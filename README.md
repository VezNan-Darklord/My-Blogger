# My-Personal-Blogger
## 项目简介
这是一个基于Spring Boot的博客项目，用于个人学习实践Spring Boot及其他配套框架。
项目启动于3月2日，预计MVP完成时间为5月22日，之后会逐步引入当下热门的后端技术和AI组件。
